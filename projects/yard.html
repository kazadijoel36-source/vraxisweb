Case notes

Challenge, solution and outcome.

Challenge

The project needed to feel like a real local creative ecosystem instead of a plain directory or marketplace.

Solution

The design uses warm paper tones, large editorial typography, product cards, creator profiles and event poster layouts to create a platform with personality.

Outcome

A flexible system across home, creators, events and market pages — useful proof for platform and directory-style work.

Build notes

Original concept build.

This project was created as original VraxisWeb portfolio work and built with HTML, CSS, JavaScript. The layout, art direction and interface structure were designed to show how a real business in this category could present itself online.
